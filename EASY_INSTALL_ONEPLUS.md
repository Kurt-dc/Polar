# Простая установка без Android Studio (для OnePlus 10 Pro)

Раньше нужно было ставить Android Studio и разбираться с Gradle sync.
Теперь сборку делает бесплатный сервис GitHub Actions в облаке — от вас
нужно только загрузить папку проекта на GitHub и скачать готовый файл.

## Шаг 1 — завести GitHub-аккаунт (если ещё нет)
https://github.com/signup — бесплатно, займёт 2 минуты.

## Шаг 2 — создать репозиторий и загрузить проект
1. На github.com нажать **"+" (вверху справа) → New repository**.
2. Название — любое, например `polar-holter`. Оставить **Private** или
   **Public**, не важно. Нажать **Create repository**.
3. На странице нового репозитория нажать **"uploading an existing file"**
   (или **Add file → Upload files**).
4. Перетащить в окно браузера содержимое папки `PolarHolter` целиком
   (можно перетащить сразу распакованный архив/папку — GitHub сохранит
   структуру подпапок) и нажать **Commit changes**.

## Шаг 3 — дождаться автосборки
1. Перейти на вкладку **Actions** вверху репозитория.
2. Там появится запуск **"Build debug APK"** — жёлтый кружок значит идёт
   сборка, зелёная галочка — готово (обычно 2–4 минуты).
3. Если кружок стал красным — сборка упала, можно прислать мне
   лог ошибки (кнопка на сам workflow run), разберёмся.

## Шаг 4 — скачать APK
1. Открыть завершившийся запуск (зелёная галочка) → внизу страницы
   раздел **Artifacts** → скачать **polar-holter-debug-apk** (это zip,
   внутри него `app-debug.apk`).
2. Распаковать zip — получите `app-debug.apk`.

## Шаг 5 — перенести APK на телефон и установить
1. Перекиньте `app-debug.apk` на OnePlus 10 Pro любым способом:
   через Google Drive/Диск, по почте себе, через USB-кабель в папку
   `Загрузки`, или просто открыть GitHub на телефоне и скачать файл прямо
   там.
2. Открыть файл `app-debug.apk` на телефоне (через приложение
   «Файлы»/«Мои файлы»).
3. Система спросит разрешение **«Установка неизвестных приложений»** —
   разрешить для того приложения, через которое открываете файл
   (Файлы/Chrome/Диск).
4. Нажать **Установить**.

## Шаг 6 — OnePlus 10 Pro (OxygenOS): отключить агрессивное энергосбережение
OxygenOS на OnePlus особенно активно убивает фоновые процессы —
это нужно обойти отдельно от стандартного диалога «Разрешить фон» в самом
приложении:

1. **Настройки → Батарея → Расход батареи приложениями** (или
   **Battery → App battery usage**) → найти **Polar Holter** →
   выставить **«Без ограничений» / «Allow background activity»**
   (не «Оптимизировано» и не «Ограничено»).
2. **Настройки → Батарея → Больше настроек батареи** →
   отключить **«Глубокая оптимизация» / «Deep Optimization»** для
   Polar Holter, если такой пункт есть (зависит от версии OxygenOS).
3. **Настройки → Приложения → Автозапуск** — включить автозапуск для
   Polar Holter, если такой переключатель есть.
4. Если после этого приложение всё равно останавливает запись в фоне —
   в OxygenOS иногда помогает закрепить приложение в списке недавних
   (свайп вверх и удержание карточки приложения → значок замка/pin).

## Итог
После установки просто откройте приложение и следуйте шагам из
`HOW_TO_RUN.md` (поиск датчика → «Записывать»). Android Studio для этого
пути вообще не нужна — только сама сборка APK происходит на GitHub.
