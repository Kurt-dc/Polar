# Как запустить Polar Holter

## 1. Установить Android Studio
Скачать с https://developer.android.com/studio (Windows/macOS/Linux).
При первом запуске мастер установки сам подтянет Android SDK — просто
соглашайтесь с настройками по умолчанию.

## 2. Открыть проект
1. Распакуйте `PolarHolter-android-mvp.zip` в любую папку.
2. В Android Studio: **File → Open** → выбрать распакованную папку `PolarHolter`.
3. Дождаться **Gradle sync** (полоса прогресса внизу окна) — при первом
   открытии Android Studio сама скачает нужную версию Gradle и все
   зависимости из `build.gradle.kts`. Это может занять несколько минут,
   нужен интернет.
4. Если sync ругается на отсутствующий `gradle-wrapper.jar` — это нормально,
   в архиве его нет (бинарный файл). Android Studio предложит
   **"Try again"/"Sync now"** и сгенерирует его сама при наличии
   `gradle-wrapper.properties` (он есть в проекте).

## 3. Подготовить телефон
1. На телефоне (Android 8.0+): **Настройки → О телефоне** → 7 раз нажать
   на «Номер сборки», пока не появится «Вы стали разработчиком».
2. **Настройки → Для разработчиков** → включить **«Отладка по USB»**.
3. Подключить телефон к компьютеру USB-кабелем, на телефоне подтвердить
   диалог «Разрешить отладку по USB».

## 4. Запустить приложение
1. В Android Studio наверху выбрать телефон в списке устройств
   (выпадающий список рядом с кнопкой ▶ Run).
2. Нажать **▶ Run 'app'** (или Shift+F10).
3. Android Studio соберёт APK, установит на телефон и запустит.
   Первая сборка может занять пару минут.

## 5. Первый запуск на телефоне
1. Приложение запросит разрешения на Bluetooth и уведомления — разрешить оба.
2. Нажать **«Разрешить фон»** — откроется системный диалог с просьбой
   исключить приложение из оптимизации батареи. Подтвердить.
   Без этого шага система может убивать запись в фоне на некоторых
   телефонах (особенно Xiaomi/Huawei/Samsung).
3. Надеть датчик Polar H10, смочить электроды.
4. Нажать **«Найти датчик»** — через пару секунд в списке должен появиться
   Polar H10 (сканирование идёт ~8 секунд).
5. Нажать **«Записывать»** напротив найденного устройства — запустится
   фоновый сервис записи, в шторке уведомлений появится постоянное
   уведомление «Polar Holter · Запись идёт».
6. Можно выключить экран — запись продолжится. Чтобы остановить —
   вернуться в приложение и нажать **«Остановить запись»**.

## Где искать результат
Записанные данные пока пишутся как CSV-файл во внутреннее хранилище
приложения: `/data/data/com.polarholter.app/files/sessions/session_<timestamp>.csv`
(доступ через **Android Studio → View → Tool Windows → Device Explorer**,
папка не видна в обычном файловом менеджере телефона — экспорт «наружу»
в файлы/врачу пока не реализован, это следующий шаг из README).

## Если что-то не собирается
Самая частая причина на первом запуске — версии SDK/Gradle подтягиваются
из интернета и требуют времени. Если Gradle sync падает с ошибкой версии
Kotlin/AGP — в Android Studio: **Tools → SDK Manager** → убедиться, что
установлен **Android SDK Platform 34** и **Android SDK Build-Tools 34**.
